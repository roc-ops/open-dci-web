# OpenDCI Vendored Schemas

Vendored copies of schemas from the [OpenDCI project](https://github.com/roc-ops/open-dci/tree/main/schemas).

- `docsis-config.jtd.json` — Canonical JTD source (for reference and codegen)
- `generated/docsis-config.schema.json` — JSON Schema 2020-12 (consumed by Monaco)
- `vendors/` — Vendor extension schemas
- `examples/` — Example DOCSIS config files in JSONC format

To update, pull the latest files from the OpenDCI repository.
